# Название проекта
Сервис планирования бюджета подразделения
## Назначение
Приложение предназначено для планирования, распределения и контроля бюджета отдельного подразделения организации. Сервис позволяет формировать бюджет на определённый период, распределять средства по статьям расходов, отслеживать фактические затраты и сравнивать их с запланированными показателями. Основная задача — упростить и автоматизировать процесс бюджетного планирования, сделать его прозрачным и удобным для ответственных сотрудников.
## Целевая аудитория
Руководители подразделений и отделов;

Сотрудники финансово-экономических служб;

Специалисты, отвечающие за планирование и контроль расходов;

Администраторы, управляющие бюджетами нескольких подразделений.
## Предметная область
Предметная область охватывает процессы бюджетного планирования и управления финансами на уровне отдельного подразделения. Это включает формирование бюджета на заданный период, распределение средств по статьям расходов, учёт плановых и фактических показателей, а также анализ отклонений и подготовку отчётности. Система работает с иерархией подразделений, временными периодами (месяц, квартал, год) и справочником статей расходов.
## Основные сущности
- Подразделение (Department) — организационная единица, для которой формируется бюджет;
- Бюджет (Budget) — совокупность плановых показателей на определённый период для конкретного подразделения;
- Статья (Budget Item / Category) — направление расходов или доходов, по которому распределяются средства;
## Основные функции
- Создание и ведение справочника подразделений;
- Формирование бюджета подразделения на выбранный период;
- Добавление, редактирование и удаление статей бюджета;
## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
